# Thunder-generated model

Copy here the folder generated by `thunder gen` for the Flexiv arm (7 joints, base `base_link`, ee `flange`):

```
thunder/<robot>_generatedFiles/
    thunder_<robot>.h
    thunder_<robot>.cpp
    <robot>_gen.h
    <robot>_gen.cpp
    <robot>_par.yaml   # installed to share/thunder_controllers/thunder
```

The default robot is `Rizon4s`. For a different one, build with `--cmake-args -DTHUNDER_ROBOT=<robot>`.
Until the files are present, the package builds without the controllers (CMake warning).

The controller uses `set_q`, `set_dq`, `get_M`, `get_C` (matrix, multiplied by dq), `get_G`,
`get_par_DYN` and `load_par` (when `thunder_par_file` is set).

**`par_DYN` must be non-zero**: with all-zero dynamic parameters M and C vanish, so the
controller refuses to configure. Fill `par_DYN` in `<robot>_par.yaml` (or point
`thunder_par_file` to another file) with the robot inertial parameters.
